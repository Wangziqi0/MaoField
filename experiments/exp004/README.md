## 零、核心公理（每个 agent 必须读）

以下 7 条不可违背。任何设计如果违反任何一条，立刻停止重新想。

1. **粒子是动态过程，不是静态定义。** 不预设物种。物种从场的演化中涌现。
2. **理解 = 内外对立统一的平衡态。** 不手写评分公式。
3. **驱动力 = 数据内在规律。** 不设 loss，不设外部目标。PDE 方程本身就是驱动力。
4. **语料是实践的记录。** 可以用语料，但不能拟合统计分布。
5. **复杂 = 最简单的重叠。**
6. **不匹配和匹配本身就是自我训练。** 目标和状态同时演化。
7. **不固定。** 反应规则、空间结构都不预设，由输入和状态动态塑造。

## 一、核心思想

**现实世界是3维的。语义是物质（token/文本）的运动。物质的运动规律在3维空间中。**

把语义理解建模为 **3维空间中的反应-扩散系统**：

```
初始状态：3D 真空（均匀场）
    ↓
token 输入 = 在 3D 空间中注入扰动（源项）
    ↓
反应-扩散 PDE 演化：
    ∂u/∂t = D∇²u + R(u)
    u = 场值（多分量）
    D = 扩散系数
    R(u) = 反应项（非线性）
    ↓
从均匀态自发涌现空间模式（Turing Pattern）
    ↓
稳定模式 = 粒子 = 对文本的理解
```

**粒子不是预先定义的——它是场演化中涌现的稳定空间模式。** 就像图灵斑图：你不需要定义"斑点"是什么，反应-扩散方程自然产生斑点。

## 三、Agent 分工

### Agent-Simulator: 3D 反应-扩散模拟器

**任务**：实现一个通用的 3D 反应-扩散 PDE 求解器。

**数学**：

多分量反应-扩散方程：

```
∂u_i/∂t = D_i ∇²u_i + R_i(u_1, u_2, ..., u_n)

u_i(x,y,z,t) = 第 i 个场分量在位置(x,y,z)、时刻t的值
D_i = 第 i 个分量的扩散系数
R_i = 反应项（非线性函数）
```

**具体要求**：

1. **网格**：32×32×32 的 3D 均匀网格。周期性边界条件。
   - 为什么32：小到能快速迭代，大到能看到有意义的模式
   - 周期性边界：没有边缘效应，空间在拓扑上是3-torus

2. **场分量数**：2个（最小的图灵不稳定性需要至少2个分量）
   - u = 激活剂（activator）
   - v = 抑制剂（inhibitor）
   - 这不是预设的"物种"——这是场的分量。涌现的模式才是"物种"。

3. **反应项**：用经典的 Gray-Scott 模型作为起点
   ```
   R_u = -u*v² + F*(1-u)
   R_v = u*v² - (F+k)*v

   F = feed rate（补充速率）
   k = kill rate（衰减速率）
   ```
   Gray-Scott 在不同 (F, k) 参数下能产生极其丰富的模式——斑点、条纹、螺旋、混沌、自复制结构。

   **注意**：F 和 k 不是固定的！它们由输入（token 注入）动态改变。这满足公理7（不固定）。

4. **PDE 求解**：显式欧拉 + 3D 拉普拉斯（7点模板）
   ```python
   laplacian_3d(u, dx):
       return (u[2:,1:-1,1:-1] + u[:-2,1:-1,1:-1] +
               u[1:-1,2:,1:-1] + u[1:-1,:-2,1:-1] +
               u[1:-1,1:-1,2:] + u[1:-1,1:-1,:-2] -
               6*u[1:-1,1:-1,1:-1]) / dx²
   ```
   周期性边界用 `np.roll` 处理。

5. **参数**：
   - D_u = 0.16, D_v = 0.08（经典比率 2:1）
   - dx = 1.0（网格间距）
   - dt = 0.5（时间步长，需检查稳定性：dt < dx²/(6*D_u)）
   - 初始 F = 0.04, k = 0.06（这个参数区间会产生斑点模式）

6. **输出**：
   - 每 100 步保存一次 3D 场的快照（numpy .npy 格式）
   - 保存元数据（参数、步数、时间）

**代码位置**：`/home/amd/HEZIMENG/MaoField/experiments/exp004/simulator.py`

**验证**：先不注入 token，跑纯 Gray-Scott。从微小随机扰动开始，看能不能自发产生图灵斑图。如果连纯 Gray-Scott 都不出模式，说明参数不对，先调参数。

### Agent-Inject: token → 3D 空间映射

**任务**：定义 token 如何在 3D 空间中注入扰动。

**核心原则**：映射必须基于文本的物质结构（词序、句子边界），不能基于 embedding 或统计。

**映射规则**：

1. **位置**：token 在 3D 空间中的位置由文本的物质结构决定
   ```
   x = token 在句子中的位置（0 到 grid_size-1，线性映射）
   y = 句子编号（如果有多个句子）
   z = 词长（字符数，归一化到 0~grid_size-1）
   ```
   - x 对应"序列位置"（物质事实：这个词在第几个位置）
   - y 对应"层级"（物质事实：第几个句子）
   - z 对应"复杂度"（物质事实：词本身有多长/多复杂）

   **注意**：这不是语义映射，是物质结构映射。"第3个词在第1个句子中、长5个字符"——这是客观事实，不是统计推断。

2. **扰动方式**：在 (x,y,z) 位置附近注入高斯形状的扰动
   ```python
   # 在位置 (px, py, pz) 注入扰动
   for ix, iy, iz in neighborhood(px, py, pz, radius=2):
       dist = sqrt((ix-px)² + (iy-py)² + (iz-pz)²)
       perturbation = amplitude * exp(-dist²/sigma²)
       u[ix, iy, iz] += perturbation
   ```

3. **扰动幅度**：
   - 基础幅度 = 0.1（所有 token 相同——不根据"重要性"加权，因为那需要判断标准）
   - 扰动同时影响 u 和 v 两个场分量（但比例不同：u 正扰动、v 负扰动，这产生不稳定性）

4. **同时**：token 注入还会局部改变 F 和 k 参数
   ```
   F_local = F_base + δF * perturbation
   k_local = k_base + δk * perturbation
   ```
   这意味着每个 token 改变了它周围的"化学环境"——不同的环境产生不同的模式。这满足公理7（不固定——环境由输入决定）。

**代码位置**：`/home/amd/HEZIMENG/MaoField/experiments/exp004/inject.py`

**测试数据**（小规模，手工构造）：

```python
test_texts = [
    "故意伤害他人身体",           # 刑法场景
    "解除劳动合同赔偿",           # 劳动法场景
    "离婚后财产分割",             # 民法场景
    "故意伤害他人身体致人重伤",    # 刑法加重（比第1条多了信息）
    "交通事故责任认定",           # 行政法场景
]
```

### Agent-Evolve: 小规模演化实验

**任务**：对每个测试文本，注入 token 后跑反应-扩散演化，记录涌现的模式。

**实验步骤**：

1. **实验 A：纯 Gray-Scott 验证**
   - 不注入 token
   - 32³ 网格，u=1 + 微小随机噪声，v=0 + 微小随机噪声
   - 跑 10000 步
   - 验证：能否自发产生图灵斑图
   - 如果不能 → 调 (F, k) 参数直到能

2. **实验 B：单文本注入**
   - 对5个测试文本，分别：
     - 初始化真空场
     - 用 Agent-Inject 的规则注入 token
     - 跑 10000 步
     - 保存最终3D场
   - 观察：不同文本是否产生不同的模式？

3. **实验 C：相似文本对比**
   - "故意伤害他人身体" vs "故意伤害他人身体致人重伤"
   - 这两个只差4个字（"致人重伤"）
   - 对比两者的最终模式：
     - 全局相似（基本结构相同）但局部不同（加重部分）
     - 如果是这样 → 场成功捕获了"量变"（多了4个字）
     - 如果模式完全不同 → 系统对输入太敏感（混沌）
     - 如果模式完全相同 → 系统对输入不敏感（信息丢失）

4. **实验 D：跨领域对比**
   - "故意伤害" vs "解除劳动合同" vs "离婚后财产分割"
   - 三个完全不同领域的文本
   - 对比最终模式：应该完全不同
   - 如果相似 → 场没有区分度

5. **实验 E：Query-Doc 匹配**
   - query: "他打我要怎么判"
   - doc1: "故意伤害他人身体"（相关）
   - doc2: "解除劳动合同赔偿"（不相关）
   - 分别演化 query 和 doc1、doc2
   - **不手写评分公式**。
   - 匹配方式：把 query 的最终场和 doc 的最终场放在同一个空间中，**继续演化**。如果 query 和 doc 是匹配的，两个场会互相融合（对立统一 → 平衡快）；如果不匹配，两个场会互相排斥（对立不统一 → 平衡慢或不平衡）。
   - **得分 = 融合速度（达到平衡的步数的倒数）或最终能量差。**
   - 这满足公理2（理解=平衡）和公理3（无外部目标，平衡本身就是度量）。

**参数扫描**：

| 参数 | 范围 | 步长 |
|---|---|---|
| F | 0.02 ~ 0.06 | 0.005 |
| k | 0.04 ~ 0.07 | 0.005 |
| D_u | 0.10 ~ 0.20 | 0.05 |
| D_v/D_u | 0.3 ~ 0.7 | 0.1 |

先跑实验 A 找到能产生模式的参数区间，再用那个参数做 B-E。

**代码位置**：`/home/amd/HEZIMENG/MaoField/experiments/exp004/evolve.py`

**输出**：
- 每个实验的 3D 场快照（.npy）
- 演化过程的能量曲线（系统总能量 vs 时间步）
- 模式的统计量（空间自相关函数、傅里叶功率谱）

### Agent-Analyze: 模式分析

**任务**：分析涌现模式的性质，设计（不是手写）匹配度量。

**分析方法**：

1. **3D 傅里叶变换**
   ```python
   F_u = np.fft.fftn(u_final)
   power_spectrum = np.abs(F_u)**2
   ```
   功率谱反映模式的空间频率结构——不同文本应该有不同的频率特征。

2. **空间自相关函数**
   ```python
   autocorr = ifft(power_spectrum)  # Wiener-Khinchin 定理
   ```
   自相关反映模式的特征长度尺度。

3. **拓扑分析**（如果模式有斑点/管道/空腔）
   - 连通分量数
   - 欧拉特征数
   - 持续同调（persistent homology）如果可行

4. **模式距离**
   - 两个场之间的距离：不手写，用场本身的物理量
   - **方案**：把两个场叠加后继续演化，测量达到新平衡所需的时间/能量变化
   - 这满足公理（不是手写评分，是物理过程本身的度量）

## 八、哲学依据

- **3维空间**：现实世界是3维的。物质第一性——语义的运动规律和物质的运动规律是同一套。
- **反应-扩散**：图灵 1952 年证明：最简单的化学反应+扩散，在均匀初态中自发涌现有序模式。这就是"粒子从过程中涌现"。
- **Gray-Scott 模型**：激活-抑制机制——激活剂催化自身增长（正反馈），抑制剂抑制激活剂（负反馈）。正负反馈的竞争 = 对立统一。
- **真空初态**：初始场均匀 = 真空。token 注入 = 物质扰动。模式涌现 = 理解。
- **匹配 = 场融合**：两个场叠加后继续演化——融合得快 = 对立面容易统一 = 匹配好。不需要人定义什么是"匹配"。

**这不是比喻。这是在 3D 空间中跑真实的物理方程。**
