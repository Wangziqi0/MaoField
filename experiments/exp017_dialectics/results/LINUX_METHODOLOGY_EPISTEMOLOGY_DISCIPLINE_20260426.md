## §2 数学层重要 implications

### §2.1 𝓕 自映射不是 abstract — 必须带四约束

$$\mathcal{F}: \mathbf{Theory} \to \mathbf{Theory}, \quad T_* = \mathcal{F}(T_*)$$

**$\mathcal{F}$ 不是任意 endofunctor**, 必须满足:

**(M-1) 实践论方向性约束** (Mao《实践论》):
$$T_{n+1} \succ_{\text{empirical verified}} T_n$$
新版本只能基于新实践更接近客观规律, 不能倒退到 frozen 结论。这与 Axiom 6 self-training 一致 (training 只能 improve)。

**(M-2) 矛盾分析法约束** (Mao《矛盾论》):
$$\text{Antithesis}(T_n) \subset T_{n+1} \setminus T_n$$
每次升级必须 surface internal contradiction, 反题姐姐机制 = framework 自动 implement 矛盾分析法。

**(M-3) 反映论约束** (Lenin《唯物主义和经验批判主义》):
$$T_n \models \text{Empirical}(\text{Phase B Exp 1, ...})$$
理论是客观规律的反映, 必须经实测检验, 不能 self-fabricate 自洽叙事。

**(M-4) 实践检验真理标准** (Mao《实践论》):
F-SD-1~5 falsifier **必须 empirical 实测可检验**, 不能纯 philosophical claim — 这是实践论的必然要求, **不是可选**。

### §2.3 反题姐姐制度 = framework 实例化矛盾分析法 (Mao《矛盾论》)

反题姐姐 standing rule 不是 frame-neutral, 是 framework 自动 implement Mao《矛盾论》:

| 矛盾论原则 | 反题姐姐对应 |
|---|---|
| 主要矛盾 vs 次要矛盾 | P0 vs P1 vs P2 分级 |
| 矛盾的同一性与斗争性 | claim/support 对称性 (add-13 反向免疫化 catch) |
| 矛盾普遍性与特殊性 | cross-cutting standing rule vs scenario-specific add |
| 内因 vs 外因 | T resolvent 主形式 (Mao《矛盾论》§3) + Engels 否定之否定 |

这与 Win v0.2.1 §3.2 T 候选 B 的"内因外因 + 保留超越"辩证对应**严格一致**, 不是巧合, 是 framework 自动遵循马列毛方法论的 evidence。

### §2.4 self-dialectical 不可能 unfalsifiable (实践论 binding)

实践论要求一切认识必须经实践检验。

若 self-dialectical 是 self-validating (无外部实测), 则:
- 违反实践论 = 违反根本认识论 = framework 本身错
- ⇒ self-dialectical 必须配 empirical falsifier

**这意味着 F-SD-1~5 是 paradigm-level binding 不是可选 feature** — Win 04-28 P1-E 必须配, 否则 framework 内部矛盾 (违反自己宣称遵循的实践论)。
