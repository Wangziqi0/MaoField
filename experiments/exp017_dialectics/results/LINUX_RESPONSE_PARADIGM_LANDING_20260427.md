## §1 Ask 1 verify: I-3 vs I-4 数学算子必然分离 ✓

### 直觉

I-3 是"测量值偏离名义值多少" (静态比较一阶矩); I-4 是"系统对外加微扰怎么响应, 响应是否线性" (动态二阶 kernel)。**前者像测体温, 后者像测心律变化对运动的响应** — 不同物理量, 数学算子上必然不同 rank。

### 严格 statement

I-3 反映保真:
$$\boxed{\;\delta_{I3} \;=\; \mathbb{E}_{\mu_*}[\rho] \,-\, \rho_{\text{nominal}} \;=\; 1.19 - 1.00 \;=\; 0.19 \quad (23\sigma\;\text{偏离})\;}$$

数学结构: **零阶 expectation functional + 一阶矩 difference**. 在 NESS 不变测度 $\mu_*$ 上对 $\rho$ 取期望减名义值。**time-independent**。

I-4 体制自证伪 + 非线性升级:
$$\boxed{\;\chi(t-t') \;=\; -\frac{\delta^2 F[\rho;\,J]}{\delta J(t)\,\delta J(t')}\bigg|_{J=0} \;\Longrightarrow\; \frac{\chi_{\text{exp}}}{\chi_{\text{theory}}^{\text{linear}}} = \frac{0.04}{59} \approx 1.7\times 10^{-3} \;\;(\text{i.e., 1500× violation in 反方向})\;}$$

数学结构: **二阶 functional derivative + Volterra causal kernel**. 取自由能 $F[\rho;J]$ 对外加场 $J(t)$ 的二阶变分, 是 time-dependent 二阶非局域算子。

### 必然分离 verdict (修订: empirical 必然分离, 不 over-claim 数学不可合并)

| 维度 | I-3 | I-4 |
|---|---|---|
| Tensor rank | 1 (一阶 moment) | 2 (二阶 functional derivative kernel) |
| 时间结构 | time-independent (NESS expectation) | time-dependent kernel $\chi(t-t')$ |
| 算子类型 | 测度 expectation (linear functional on observables) | bilinear kernel on $J(t)\otimes J(t')$ space |
| Phase B anchor | ⟨ρ⟩=1.19 (Stage B/NESS, 23σ 偏 nominal) | χ_exp=0.04 vs χ_theory=59 (linear response break, 1500×) |
| 对应 Σ 算子 | T-resolvent + V stationarity 判据 | $\Sigma_1$ 二阶 Volterra kernel |

**注 (paper-review P0-2 patch)**: 数学层 I-3 与 I-4 *可以* formally 嵌入同一 generating functional (e.g., $W[J] = \log Z[J]$ 的 Taylor 展开 1 阶 + 2 阶 系数同住一个 $W$); 因此 "数学算子必然分离" 是 false dichotomy。**真正分离来自 empirical**: I-3 anchor Stage B/NESS 静态实测 ⟨ρ⟩, I-4 anchor χ violation 动态实测响应 — 两个独立 empirical signal, **反映论 (M-3) binding 下不可 collapse 到一条 invariant**, 否则丢失独立物质 anchor。

形式化 (修订): I-3 $\in$ tensor rank-1 component $W^{(1)}[J]|_{J=0}$ 的 NESS 投影 + 1 个 empirical signal (Stage B ⟨ρ⟩); I-4 $\in$ tensor rank-2 component $W^{(2)}[J(t), J(t')]|_{J=0}$ 的 Volterra kernel + 1 个独立 empirical signal (χ violation). **Empirical anchoring 双 signal 独立 → M-3 反映论 binding → 不可 collapse**。

### 机制

为什么不同 rank 必然不同 invariant: 反映论 (M-3) 要求"理论 reflect 客观规律", 但客观规律自身有**多 rank 结构** — 一阶矩 (mean fidelity, 反映"系统在哪") 与二阶响应 (susceptibility, 反映"系统如何应对扰动") 是不同物理事实。把它们 collapse 到一条 invariant 等于把两条独立 empirical signal merge, **违反 M-3 一一对应 reflection 原则**。
