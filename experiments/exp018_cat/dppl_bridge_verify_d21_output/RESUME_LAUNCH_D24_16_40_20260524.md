### §2.1 FAIL 1 root cause: PPID ≠ 1

`setsid(1)` (util-linux) 之 default behavior:
- 若 calling process 是 process group leader, setsid 必 fork (因 process group leader 不能 create new session)
- bash 之 `&` background 让 child 成为 new process group leader → setsid 必 fork
- setsid 之 fork: parent (416997) wait child (417000), parent **不立即 exit**
- 因此 child 之 PPID = parent (416997), 不是 init

**修复 hypothesis** (不擅自 实施, 留 PI 决): 用 `setsid --fork` (或 `-f`) flag, 让 parent 立即 exit, child orphan 到 init. PPID 之 reparent 到 1 在 parent (416997) 死之后.

**reality binary fact**:
- process group 已 detach (新 PGID 417000 ≠ task harness 之 PGID)
- `disown` 让 bash job table 不挂
- nohup 屏蔽 SIGHUP
- task harness 之 SIGTERM 一般 send to PID + process group, 我之 process group 独立, 不在 kill scope
- 但 parent 416997 若 死, SIGTERM 之 propagate 给 child 417000 之 risk 留 PI 决
