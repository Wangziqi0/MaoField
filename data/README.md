# Data

This directory hosts data summaries and lightweight result artifacts suitable
for version control. Large / raw data are excluded via `.gitignore` and
regenerated by reproduction scripts.

## What lives here

- **Result summaries** (small CSVs, JSONs): mean nDCG scores, attractor k* values, ablation tables
- **Processed data** that is worth tracking across git history
- **Pointers** (`.pointer.md` files) to external data sources (BEIR datasets, embedding caches, etc.)

## What does NOT live here

- Raw BEIR datasets (use official downloads, see `scripts/setup.sh`)
- Per-query output files (too large, regeneratable)
- Embedding caches (regenerate with provided scripts)
- Intermediate field states (`.bin`, `.npz` — reproducible)

## Data integrity

All tracked result files carry a comment header with:
- The experiment that generated them (e.g., `exp017 Block IV`)
- The commit SHA of the code that generated them
- A timestamp
- A 1-line description of the generating command

Example header:
```csv
# Generated by exp017 Block IV (commit abcdef1) at 2026-04-13T10:40:00Z
# Command: cargo run --release -- --block=IV --dataset=nfcorpus
# Columns: dataset, IV-A, IV-B, IV-C, IV-D
```
