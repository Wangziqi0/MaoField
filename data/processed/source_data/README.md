# MaoField Source Data — R4 release-engineering candidate

This directory contains the processed tables and workbooks underlying the published display items. The R4 change repairs release metadata only: the eight workbook names are recorded as V3, byte sizes and SHA-256 identities are read from the final archive, and the Figure 5 workbook size is corrected. No cell, scientific value, endpoint, threshold, statistic or claim was changed.

Use `SOURCE_DATA_BUILD_RECORD.json` for byte identities and workbook sheet ranges, and `DATA_DICTIONARY.md` for CSV columns. A final DOI, preferred citation and licence require PI adoption before public release.
