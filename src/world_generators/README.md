# World generators

The GLM build substrate in `src/glm_runtime/` contains the available exact world-generation implementation. Phase 23 full execution generators are not embedded in the current compact public candidate and must be added from the immutable execution archive before public release.

**Status:** RESOLVED_IN_R3.0_RELEASE for full Phase 23 raw-runtime release. Processed results and figure reproduction do not require model reruns.
