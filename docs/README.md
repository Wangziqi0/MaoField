# Documentation

Extended documentation for the MaoField framework.

## Contents (planned for v0.1.0)

| Document | Scope |
|---|---|
| `philosophy.md` | The seven axioms in full (English + 中文), motivation, relationship to dialectical-materialist tradition |
| `mathematics.md` | Detailed PDE derivations, symmetry-breaking analysis, attractor-capacity theorem |
| `roadmap.md` | Long-term research roadmap, Block V+ design, A/C jumps |
| `CONTRIBUTING.md` | How philosophical, mathematical, and engineering contributions are integrated |
| `GLOSSARY.md` | Terminology reference (dialectical terms, mathematical terms, AI/IR terms) |
| `FAQ.md` | Frequently asked questions (especially on "why dialectical materialism?") |
| `HISTORY.md` | Project timeline: key experiments, theoretical shifts, acknowledgments |

## Design

Documentation is layered for three audiences:

1. **Academic readers** → formal paper in `paper/`
2. **Open-source contributors** → this directory (clear prose, references, pointers)
3. **General/curious readers** → blog-style articles (external; will be linked here)

## Status

Documents are in preparation. The main README.md at repository root provides
a self-contained introduction suitable for first-time visitors; this directory
will be populated with depth materials ahead of the v0.1.0 release.
