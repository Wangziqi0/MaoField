proof, not as a paper-ready manuscript, and not as empirical evidence.

```text

under what material and mathematical conditions can metric outputs across
black-box evaluation charts be treated as the same object?
```

## Technical Commitments

The adopted programme must be translated into finite objects, not only
philosophical language:

- define evaluation charts, e.g. `c = (P, T, J, R, D, w, A_g, S)`;
- define metric outputs as chart-dependent objects `M_c(model)`;
- require identity / transport / invariance conditions before two outputs are
  treated as the same metric object;
- give defect certificates when identity fails;
- use the Open-MaoField order-defect theorem as the first finite exact
  certificate, not as a completed general theory.

Suggested next technical objects:

- audit-order instability index `OI(w)=||D_w||`;
- pointwise chart sensitivity `OI_w(K)=||R_{Q->B}K-R_{B->Q}K||_w`;
- exact certificate library for small finite weighted charts;
- residual metric audit protocol v0.1 with weight-form, order-defect,
  projection, judge-axis, contamination-axis, aggregation, and ranking-stability
  checks.
