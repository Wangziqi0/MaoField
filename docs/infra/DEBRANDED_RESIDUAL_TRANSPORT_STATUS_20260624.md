## Current Mathematical Object

The best current Mode A object is not a scalar dashboard metric and not a raw
hypercube cell value. It is a finite scale-lattice residual transport system:

```text
scale s in Sigma
admissible triple (X_s, w_s, N_s)
weighted projection P_s = Pi_{N_s_perp,w_s}
coarsening map C_rho: H_s -> H_s'
local residual R_s(K) = P_s K_s
edge defect D_rho(K) = C_rho P_s K - P_s' C_rho K
square holonomy defect H_square(K)
```

The core question is:

```text
After scalar metrics, main effects, decode artifacts, smooth generation trends,
nuisance subspaces, and coordinate freedom are removed, does any stable
non-scalar residual structure remain?
```

If yes, the project should characterize its transport stability, rank, null
model separation, and gluing obstruction.

If no, the no-go result shows that complex collapse narratives were scalar,
coordinate, scale, or projection artifacts.

## Junior-High Explanation

The old project found many apparent patterns. The stricter reviews showed that
most of them could be explained by simpler shadows: one-number metrics,
position or frequency effects, decode choices, smooth trends, or coordinate
choices.

The new project asks a cleaner question. Imagine wiping off all easy-to-fake
marks from a table. If a real shape is still left, study that shape. If nothing
is left, then the previous story was only made by the marks we wiped away.

That is the point of the debranded residual transport direction.
