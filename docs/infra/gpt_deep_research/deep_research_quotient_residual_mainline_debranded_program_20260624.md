# MaoField 商残差审计与去品牌化研究程序

## 结论页

本次 bundle 要求把 Mode A 与 Mode B 严格分离，而且只允许把 MaoField 当作“去魅后的经验材料与概念矿石”。按零上下文提示、`STATE.md`、研究索引和三份 adoption note 的合流口径，当前**最强的数学着陆**已经不是 q4 残差、也不是 16-cell 交互场，而是一般 nuisance 商残差母对象
\[
R_t=\Pi_{\mathcal N^\perp,w}K_t,
\]
其中 \(X\) 是预注册有限空间，\(w\) 是 outcome-independent 正权重，\(\mathcal N\) 是预注册 nuisance 子空间；report(19) 把它提升为母对象，report(21) 把它形式化为“可容许三元组 \((X,w,\mathcal N)\) + 有限维 Hilbert 商空间 + ANOVA/no-go/自然性/对易子/gluing”的框架。也就是说，真正落地的不是“发现了一个场”，而是“给出了一个可被证明、可被击杀、可被失败地证明不存在的对象架构”。

Mode B 下当前**最强且唯一合法的 MaoField 专属说法**仍然非常窄：项目目前只支持零 GPU 的 formal prereg、schema/occupancy 审核、以及三份 smoke 原始行上可复算的一个小型 strict-additive residual hint；它的正式边界仍是 `insufficient_artifact` 与 `smoke_conjecture_only`，不得升级为 observed interaction field、observed residual field、LOSO 通过、F3 阳性、glass-box 突破、训练授权或新 loss 授权。当前 bundle 还明确写死：没有 full panel，没生成 16-cell full-panel aggregate，也没有任何新实验阳性结果。就证据纪律而言，这不是“保守表述”，而是仓库已经把上界锁死。

因此，报告(17)、(19)、(21)的真实数学 landing 可以一句话概括为：**report(17) 完成“问题化”，report(19) 完成“母对象化”，report(21) 完成“形式化与可击杀化”**。它们共同把 MaoField 从“旧品牌叙事的防御”压缩成一个有限维研究程序：如果 \(R_t\) 在噪声、秩、随机轴、同维随机子空间、coarsening、commutator leakage、gluing sanity 下仍存活，那么它才是结构；如果它被这些门一一杀死，那么负结论同样有价值，因为它证明旧叙事不过是标量影子、秩一阴影、nuisance 泄漏或坐标自由度。

我给出的最终严厉 verdict 是：**Mode A 现在值得做的，不是继续给 MaoField 找“更高级的 branding”，而是把有限维商残差理论做成一个双向有价值的程序；Mode B 现在允许说的，仍只有“零 GPU 形式预注册 + smoke 级小残差提示”，再多一步就是越界。**

## 既有报告的真实着陆

### 报告十七

report(17) 的真实落点，不是“发现了 quotient residual”，而是**把问题下沉到 quotient residual existence problem**。它在 adoption note 中把最强抽象问题写成：给定有限乘积空间 \(X\)、正权重 \(w\)、预结果 nuisance 子空间 \(\mathcal N\) 与观测场 \(K_t\)，考察
\[
R_t=\Pi_{\mathcal N^\perp,w}K_t
\]
能否作为稳定、非标量对象存活。它同时明确给出双向价值：正面答案必须越过 noise、rank-1 shadow、random same-dimension subspace、random partition 与 coarsening/refinement 稳定性；负面答案同样有价值，因为它可以把复杂叙事压回 scalar projection、low-rank template、nuisance 或 coordinate freedom。这里的 landing 是“问题结构被钉住”，不是“对象已经被观察到”。

从类别上分，report(17) 的**定义部分**是有限带权乘积空间、strict additive interaction field \(I_i=\Pi_{A^\perp,w}K_i\)、更一般的商残差 \(R=\Pi_{\mathcal N^\perp,w}K\)、粗化算子、张量残差、局部 gluing mismatch；其**定理议程**是“先固定 carrier/weights/nuisance，再谈唯一分解与对象同一性”；其**no-go 标准**是 noise floor、rank-1 阴影、partition artifact、随机轴与随机同维子空间不可区分；其**仍属隐喻的部分**则是 sheaf、holonomy、哲学 landing，如果没有 local sections、restriction maps、overlap mismatch 与 measurable obstruction，就不能当对象来用。它还明确承认：当前真正受 bundle 工件支持的，只是未来 q4 full-panel residual 路径和未来的 `Q_freq4 × B_tokenpos4` interaction candidate；并不存在当前可宣称的 observed field。

report(17) 的**smoke feasibility 着陆**也必须说准：它自己并没有产生新的 empirical artifact，它推动的只是一个 zero-GPU prereg 设计方向，后来对应到 `HYPERCUBE_INTERACTION_ANALYSIS_PREREG_DESIGN_20260623.md`。README 也把这件事记得很清楚：report(17) 的 refresh 一并纳入的是“math-ore quotient residual audit + adoption note + hypercube interaction prereg design”，而不是 full-panel 结果。也就是说，report(17) 的仓库着陆是**设计化**，不是**证据化**。

### 报告十九

report(19) 的真实落点是**母对象化**。它把 `I_t=\Pi_{A^\perp,w}K_t` 明确降级为 `R_t=\Pi_{\mathcal N^\perp,w}K_t` 的一个 strict additive 特例，把 functional ANOVA/Hoeffding、multiscale naturality、tensor rank、projection-evolution commutator、gluing obstruction 全部改写成围绕 \(R_t\) 的派生结构，而不是各自独立的 positive claim。这个动作非常关键，因为它防止研究被绑在当前 `4×4` carrier 上，也防止把 “加性主效应是全部 nuisance” 偷渡成先验。

从类别上分，report(19) 的**定义部分**是固定有限带权乘积空间 \(X\)、预结果 nuisance 子空间 \(\mathcal N\)、商残差族 \(R_t\) 及其 special case \(I_t\)；其**定理议程**包括 additive-interaction uniqueness、rank-1 scalar-shadow no-go、coarsening/projection naturality、random same-dimension subspace indistinguishability、projection-evolution commutator obstruction；其**no-go 规则**则由 kill suite 给出：provenance/schema、full-panel completeness、strict additive annihilation、matched mean/slope、rank/amplitude、random equal-size partitions、within-q shuffle、bad-axis control、same-dimension random subspace、coarsening/refinement、principal-angle stability、gluing sanity。它同时把哲学 landing 严格翻译成数学语句：contradiction 只等于 non-additive interaction / non-commuting operation / gluing obstruction，essence 只等于 quotient-surviving residual，其他不落地者一律不算。

report(19) 相比 report(17) 的新增，不是新证据，而是**把研究程序从“值得追的问题”推进到“有明确母对象与 kill framework 的问题”**。这就是为什么研究索引把 report(19) 记成“底层对象是一般 nuisance quotient residual；interaction fields、ANOVA、tensor rank、coarsening、commutator、gluing 都是 derived structures；Mode B 仍是 `insufficient_artifact`，smoke 仍是 `smoke_conjecture_only`”。因此，report(19) 的 landing 仍然是纯数学/设计层，不是 empirical landing。

### 报告二十一

report(21) 的真实落点是**形式化与定理化**。它没有推翻 report(19)，而是把 report(19) 形式化成：可容许三元组 \((X,w,\mathcal N)\)、有限维 Hilbert 商空间中的最小范数代表、产品权重与非产品权重 ANOVA 的边界、rank-1 shadow no-go、随机同维子空间不可区分、coarsening/projection 非自然性、projection-evolution commutator 的 leakage 解释，以及 measurable gluing obstruction。研究索引把这一层叫作“finite-ANOVA / no-go formalization”，adoption note 也把它写成“claim-source mathematical formalization, not new MaoField evidence”。

从类别上分，report(21) 的**定义部分**最扎实：它给出 admissible triple 的三条硬条件，给出 \(R_t\) 是 \([K_t]\in H_w/\mathcal N\) 的唯一最小范数代表元，给出两轴 strict additive 分解与 product-weight Hoeffding 分解，给出 coarsening 算子、commutator、gluing obstruction 的可测定义。它的**可立即证明的定理部分**包括：最小范数代表唯一性、两轴加权可加—交互分解唯一性、产品权重下 Hoeffding 正交分解、rank-1 shadow collapse、random same-dimension subspace indistinguishability、coarsening 与投影交换的充要条件、commutator 的 sector leakage 块矩阵公式。它的**no-go 部分**同样清楚：若权重非产品或支撑不满，就不能把层级投影偷叫 canonical Hoeffding；若 \(\sigma_2/\sigma_1\) 过低，就优先按 rank-1 shadow 处理；若真轴不优于随机轴或随机同维子空间，则对象无坐标不变意义；若 coarsening 不自然，则对象是 partition artifact；若 overlap mismatch 可以被 local nuisance 吸收，则 sheaf 语言作废。

report(21) 的**smoke feasibility**与**禁止性证据声明**也必须说死：它没有新增 smoke 结果，它只是把 future finite weighted ANOVA / quotient residual analysis 应如何被 kill 写得更严格；Mode B 仍然保持 `insufficient_artifact`，现有三份 smoke interaction residual 仍只配 `smoke_conjecture_only`；full panel、observed field、LOSO、F3、glass-box、training、新 loss 全部保持 blocked。换言之，report(21) 完成的是“形式化的下沉”，不是“证据的上升”。

## 形式化定义

### Mode A

设 \(X=\prod_{j=1}^d A_j\) 为有限乘积空间，\(w:X\to(0,\infty)\) 为正权重且 \(\sum_{x\in X}w(x)=1\)，定义加权 Hilbert 空间
\[
H_w=\mathbb R^X,\qquad \langle f,g\rangle_w=\sum_{x\in X}w(x)f(x)g(x).
\]
我把**可容许三元组**定义为 \((X,w,\mathcal N)\)，其中 \(X\) 的轴、cells 和 coarse/fine 关系必须预注册，\(w\) 必须 outcome-independent，\(\mathcal N\subset H_w\) 必须是 pre-outcome nuisance 子空间，允许由常数项、主效应、预注册 slope、预注册 smooth trend、matched mean/slope 模板、预注册 baseline 模板组成，但不允许把从 \(K_t\) 中事后“看出来”的方向塞回去。

在这个定义下，**商残差族**定义为
\[
R_t=\Pi_{\mathcal N^\perp,w}K_t.
\]
它等价于 \(K_t=n_t+R_t\) 的唯一正交分解，其中 \(n_t\in\mathcal N\), \(R_t\in\mathcal N^\perp\)，同时也是商类 \([K_t]\in H_w/\mathcal N\) 的唯一最小范数代表元，所以 \(\|[K_t]\|_{H_w/\mathcal N}=\|R_t\|_w\)。这一步把“residual”从随手减背景提升成了真正的 quotient object。

在两轴载体 \(X=Q\times B\) 上，我把**加权交互场**定义为 strict additive nuisance 的正交余量。令
\[
\mathcal A=\{\mu+\alpha(q)+\beta(b)\},
\]
则
\[
I_t=\Pi_{\mathcal A^\perp,w}K_t.
\]
于是任意 \(K\in H_w\) 都唯一分解为
\[
K(q,b)=\mu+A(q)+B(b)+I(q,b),\qquad I\in\mathcal A^\perp,
\]
并且 \(I=0\iff K\in\mathcal A\)。在当前 `Q_freq4 × B_tokenpos4` 具体化中，ambient dimension 为 \(16\)，strict additive dimension 为 \(7\)，interaction dimension 为 \(9\)。

**有限 ANOVA 分解**需要分成两类。若权重是产品型
\[
w(x)=\prod_{j=1}^d w_j(x_j)
\]
且各轴满支撑，则可以定义 weighted conditional expectation \(E_S\) 与 Hoeffding 分量 \(f_S\)，从而得到
\[
f=\sum_{S\subseteq[d]}f_S,\qquad \langle f_S,f_T\rangle_w=0\ (S\neq T),
\]
这时“主效应、二阶交互、三阶交互”才是 canonical 的。若权重不是产品型，或者有空 cell / 零权重，则只能做**层级加权投影分解**，不能偷称 canonical Hoeffding。因而我把一般权重下的 high-order 程序写为一串预注册嵌套 nuisance spaces
\[
\mathcal N_{\le 0}\subset \mathcal N_{\le 1}\subset\cdots\subset \mathcal N_{\le d}=H_w,
\]
并定义第 \(k\) 阶层
\[
\mathcal L_k=\mathcal N_{\le k}\cap \mathcal N_{\le k-1}^{\perp,w}.
\]
这样即使没有产品权重，也仍有清楚的 finite-dimensional order-by-order program。

我把**随机轴零模型**定义为：在保持真轴 bin 个数与 cell counts 不变的前提下，从 outcome-independent 的等规模分箱集合中随机抽取轴映射 \(\tilde\beta\)，比较某个预注册统计量 \(\Psi(\beta_\star;K)\) 与 \(\Psi(\tilde\beta;K)\) 的经验分布；若真轴不优于这族随机轴，则对象被 `killed_by_random_axis`。与之配套，**随机同维子空间零模型**定义为：在 \(V=\mathcal N^\perp\) 中抽取随机 \(r\)-维子空间 \(E\)，比较 \(\Phi(E_{\mathrm{true}},K)\) 与 \(\Phi(E,K)\) 的分布；如果真子空间不优于随机同维子空间，则它没有坐标不变意义。 report(21) 已经给出了这组 no-go 的理论动机。

我把**rank-shadow 诊断量**定义为：把 \(R_t\) 按固定 cell 顺序堆成矩阵 \(M\in\mathbb R^{T\times |X|}\)，考察奇异值比
\[
\rho_{\mathrm{rank}}=\sigma_2(M)/\sigma_1(M)
\]
和适当的 centered amplitude。若 \(\rho_{\mathrm{rank}}\) 很小，则 residual 更接近“固定模板 \(\times\) 单一标量轨道”而非多方向结构。当前 interaction prereg skeleton 直接把 `weighted_uncentered_sigma2_over_sigma1` 作为核心统计，并把 `<0.10` 设为 `killed_by_rank1_shadow` 的机械阈值。

我把**coarsening 映射**定义为带权块平均：
\[
(C_\rho f)(y)=\frac{1}{w_c(y)}\sum_{\rho(x)=y}w_f(x)f(x),\qquad
w_c(y)=\sum_{\rho(x)=y}w_f(x),
\]
并把**coarsening naturality defect**定义为
\[
\Delta_\rho(K)=\|C_\rho \Pi_{N_f^\perp,w_f}K-\Pi_{N_c^\perp,w_c}C_\rho K\|_{w_c}.
\]
若 \(\Delta_\rho\) 系统性大，则对象只是 partition artifact。

我把**projection-evolution commutator**定义为
\[
\mathcal C=[P,T]=PT-TP,\qquad P=\Pi_{\mathcal N^\perp,w}.
\]
在 \(H_w=\mathcal N\oplus\mathcal N^\perp\) 的块矩阵下，
\[
T=\begin{pmatrix}A&B\\ C&D\end{pmatrix},\qquad
[P,T]=\begin{pmatrix}0&-B\\ C&0\end{pmatrix},
\]
因此 commutator 的含义不是玄学“运动性”，而是 nuisance sector 与 residual sector 之间的泄漏。

最后，我把**gluing obstruction**定义为：给一族局部 chart \(U_\alpha\subseteq X\)，局部 residual sections
\[
s_\alpha=\Pi_{N_\alpha^\perp,w_\alpha}(K|_{U_\alpha}),
\]
普通 restriction maps \(r_{\alpha\beta}\)，以及 overlap mismatch
\[
\delta_{\alpha\beta}=r_{\alpha\beta}(s_\alpha)-r_{\beta\alpha}(s_\beta),
\]
再定义 gauge-minimized obstruction
\[
\operatorname{Obs}(K)=\inf_{n_\alpha\in N_\alpha}\left(
\sum_{\alpha<\beta}
\left\|
r_{\alpha\beta}(K|_{U_\alpha}-n_\alpha)-r_{\beta\alpha}(K|_{U_\beta}-n_\beta)
\right\|^2_{w_{\alpha\beta}}
\right)^{1/2}.
\]
只有当 \(\operatorname{Obs}(K)>0\) 且在预注册允许的局部 nuisance 扩张下仍显著为正时，sheaf/gluing 语言才保留；否则一律丢弃。

### Mode B

回到 MaoField 的证据门禁，上述所有对象都只能作为“未来分析对象或 kill test 目标”回译。当前 concrete carrier 是
\[
X=Q_{\mathrm{freq4}}\times B_{\mathrm{tokenpos4}},
\]
其中第二轴由
\[
\mathrm{position\_bin}=\min\!\left(3,\left\lfloor \frac{4(\mathrm{token\_pos}-1)}{63}\right\rfloor\right)
\]
固定派生，source-only weights 固定在 schema 里，strict additive nuisance space 维数为 \(7\)，interaction residual dimension 为 \(9\)。这只说明 carrier、weights、nuisance policy 和 forbidden axes 已被预注册化，并不说明 residual object 已被观察。

当前 Mode B 的工件映射也很清楚：`Q4_HYPERCUBE_ZERO_GPU_AUDIT_20260623.md` 只支持 `formal_prereg_only`；`Q4_HYPERCUBE_INTERACTION_SMOKE_AUDIT_20260623.md` 只支持 `smoke_conjecture_only`；`scripts/q4_hypercube_interaction_prereg_analysis.py` 的最强可能 verdict 只是 `eligible_for_next_design_review_only`；而在没有未来 aggregate、没有完整 null blocks 或 metadata/rows 不合格时，它会机械地落到 `insufficient_artifact` 或 `invalid_artifact`。这就是当前 MaoField 允许的全部落地语言。

## 定理议程与击杀套件

### 可立即证明的命题

**命题一：商残差最小范数代表定理。** 对任何可容许三元组 \((X,w,\mathcal N)\) 与任何 \(K_t\in H_w\)，\(R_t=\Pi_{\mathcal N^\perp,w}K_t\) 是 \([K_t]\in H_w/\mathcal N\) 的唯一最小范数代表元。这个命题现在就成立，因为它只依赖有限维正交投影，不依赖任何未来面板数据。

**命题二：加权可加湮灭唯一性定理。** 在两轴有限空间 \(Q\times B\) 上，对任意正权重 \(w\)，令 \(\mathcal A=\{\mu+\alpha(q)+\beta(b)\}\)。则每个 \(K\in H_w\) 唯一分解为 \(K=\mu+A+B+I\) 且 \(I=\Pi_{\mathcal A^\perp,w}K\)；并且
\[
I=0\iff K\in\mathcal A.
\]
这是后续所有 “contradiction = non-additivity” 落地的最低数学核心。

**命题三：rank-1 scalar-shadow collapse 定理。** 把 residual 序列堆成 \(M\in\mathbb R^{T\times |X|}\)。若 \(\operatorname{rank}(M)=1\)，则存在固定模板 \(u\in H_w\) 和标量轨道 \(c_t\) 使
\[
R_t=c_tu.
\]
于是任何“多方向动态”“高阶矛盾运动”都坍缩为单模板幅度变化。实际分析中，用 \(\sigma_2/\sigma_1\) 作为近 rank-1 诊断量。

**命题四：随机同维子空间不可区分性定理。** 在各向同性零模型 \(Z\sim\mathcal N(0,\sigma^2 I_V)\) 下，\(\|\Pi_E Z\|_w^2/\sigma^2\) 的分布只依赖 \(\dim E=r\)，不依赖 \(E\) 的具体位置。因此，如果真子空间统计量不优于随机同维子空间，那么它不具有坐标不变意义。这个命题给出了 `same-dimension random subspace guard` 的严格理论基础。

**命题五：coarsening naturality 充要条件。** 令 \(P_f=\Pi_{N_f^\perp,w_f}\), \(P_c=\Pi_{N_c^\perp,w_c}\)。则
\[
C_\rho P_f=P_c C_\rho
\]
当且仅当
\[
C_\rho(N_f)\subseteq N_c,\qquad C_\rho(N_f^\perp)\subseteq N_c^\perp.
\]
因此，天然性不是“看起来像”，而是一个明确的算子交换条件；失败则直接说明 partition artifact。

**命题六：projection-evolution leakage 定理。** 在 \(H_w=\mathcal N\oplus\mathcal N^\perp\) 的分块下，
\[
[P,T]=0 \iff T(\mathcal N)\subseteq\mathcal N,\ \ T(\mathcal N^\perp)\subseteq\mathcal N^\perp.
\]
因此非零 commutator 的严格含义就是 residual sector 与 nuisance sector 之间存在泄漏；在实证上，它只有在排除 matched templates、random axes 与 rank-shadow 后才有对象性。

**命题七：gauge-absorbable gluing no-go。** 若 \(\operatorname{Obs}(K)=0\)，则局部 residuals 可以在允许的局部 nuisance gauge 下拼成全局对象；若某个所谓 obstruction 只要略微扩大局部 nuisance 就消失，则它不是几何结构，只是 gauge artifact。这个命题把 sheaf 语言的使用条件严厉地降到“可测 overlap mismatch 是否不可吸收”。

### 需要未来数据的经验猜想

**猜想甲：非标量 persistence 猜想。** 存在某个可容许三元组 \((X,w,\mathcal N)\)，使得 \(\|R_t\|_w\) 在完整 panel 上跨 held-out seed / generation blocks 稳定高于噪声地板，且不被 rank-1 shadow、random axes、same-dimension random subspaces 与 coarsening failure 杀死。只有未来 provenance-checked aggregate 与完整 null blocks 才能检验这一点。

**猜想乙：随机轴分离猜想。** 真正 outcome-independent 的结构轴，会在预注册统计量上稳定优于等规模随机分箱、within-q shuffle 与坏轴 `audit_block_id`；若做不到，就应该把对象判成 `killed_by_random_axis`。这不是当前 smoke 工件能决定的事，因为 smoke 审计明确列出了这些控制都还缺失。

**猜想丙：多尺度自然性与恢复路径猜想。** 若某个 residual object 真有结构同一性，则它在 `q8→q4→q2` 与 `tokenpos8→4→2` 上应保留受控的 \(\Delta_\rho\)，并在 generation 路径上表现为可比主子空间与主角，而不是随 coarse/grain 选择任意跳转。若不成立，则应把“动态相图”“恢复轨迹”“holonomy”之类措辞一律退出。

### 零 GPU 击杀套件

Mode B 中最有价值的不是某个 smoke 数字，而是**对象必须先配刑具**。现在已有两套阈值来源：其一，interaction prereg skeleton 已经硬编码了 `interaction_to_noise_median_ratio <= 1.0` 则 `killed_by_noise_floor`，`weighted_uncentered_sigma2_over_sigma1 < 0.10` 则 `killed_by_rank1_shadow`，缺失任一 prereg null block 则 `insufficient_artifact`；其二，现有 q4 fold-local 参考脚本要求 `delta_r2 >= 0.02`、matched-mean 稳定分数 \(\ge 0.70\) 且 \(|z|\ge 2.58\)、`sigma2/sigma1 >= 0.25`、残差振幅高于 \(2\times\max\{\)bootstrap p90, rank1-control p90\(\}\)，并附加 random mean-null projection multiplicity guard。interaction 线若想成为严肃对象，阈值不应比 q4 residual 线更松。

我建议把 brutal zero-GPU kill suite 固化为以下判决逻辑。首先是 provenance/schema/digest：若 `artifact_kind`、`aggregate_schema_id`、`repo_head`、`builder_script_sha256`、`raw_jsonl_sha256`、`axis_definitions`、`source_only_weights` 或 `rows` 缺失或不匹配，直接 `invalid_artifact`。其次是 full-panel completeness：不是恰好 `5 seeds × 10 generations = 50` 行，或种子/代缺失，直接 `insufficient_artifact`。再次是 strict additive annihilation：中位数 residual/noise 比 \(\le 1\) 则 `killed_by_noise_floor`。再后是 matched mean/slope、rank/noise、random equal-size partition、within-q shuffle、bad-axis、same-dimension random subspace、coarsening/refinement、principal-angle stability 与 gluing sanity；任一关键门失败，就分别落到 `killed_by_rank1_shadow`、`killed_by_random_axis` 或 `killed_by_coarsening`。全部存在且未死，最强也只是 `eligible_for_next_design_review_only`。

把这个 kill suite 回投到当前 bundle，结论完全机械：现在没有 PI-approved full panel，没有 16-cell full-panel aggregate，没有完整 `null_tests` 八块，没有 held-out seed / generation-block leave-out 的 interaction 输出，没有 random partitions / same-dimension subspace / coarsening 的未来结果块，所以母对象层面的当前 verdict 只能是 `insufficient_artifact`；而 smoke 审计层面只能保留 `smoke_conjecture_only`。没有任何“解释空间”可以把它往上抬。

## Codex 实现交接

仓库里已经有一条非常清楚的本地实现链。`scripts/build_hypercube_schema_20260623.py` 负责产生 `q4_tokenpos4_hypercube_20260623` schema，锁定 `Q_freq4 × B_tokenpos4` carrier、assignment policy、cells、occupancy、mandatory nuisance、strict additive nuisance、forbidden axes 与 claim policy。`docs/infra/math_turn_20260622/Q4_HYPERCUBE_ZERO_GPU_AUDIT_20260623.md` 负责只用 smoke raw 验证 16/16 cell 非空，结论仅为 `formal_prereg_only`。`scripts/q4_hypercube_interaction_smoke_audit.py` 对三份 smoke raw 复算小型 strict-additive residual，输出 canonical smoke audit，结论仅为 `smoke_conjecture_only`。`scripts/q4_hypercube_interaction_prereg_analysis.py` 则是未来 aggregate 的 fail-closed 分析闸门。与此同时，`highorder_raw_logprob_panel.py` 仅提供受 PI token 保护的 full-panel generator 与 dry-run 计划，不属于本次零 GPU handoff 的可立即执行部分。

Codex 现在就可以稳定复用的**精确 JSON 合约**已经写在 `q4_hypercube_interaction_prereg_analysis.py` 里。它要求的顶层字段是：`artifact_kind`、`aggregate_schema_id`、`repo_head`、`builder_script_sha256`、`raw_jsonl_sha256`、`axis_definitions`、`source_only_weights`、`rows`。其中 `artifact_kind` 必须是 `maofield_q4_tokenpos4_interaction_full_panel_aggregate`，`aggregate_schema_id` 必须是 `q4_tokenpos4_interaction_full_panel_20260623`，总行数必须是 50，对应 seeds `[1,2,3,4,42]` 与 generations `0..9`。每个 row 至少要有 `seed`、`generation`、`checkpoint_identity`、`cell_counts`、`cell_mean_logprob`、`cell_var_logprob`；同时还必须有 `null_tests` 下的八个结果块：`matched_mean_slope`、`random_equal_size_partition`、`within_q_position_shuffle`、`bad_axis_audit_block_id`、`same_dimension_random_subspace`、`coarsen_refine_naturality`、`principal_angle_stability`、`gluing_sanity`。

## 最底层研究程序陈述

去掉 MaoField 品牌后，我认为真正值得留下的 bottom-level program 只有一句，而且它在阳性与阴性两端都值钱：

\[
\textbf{寻找或否证一个可容许三元组稳健的商残差族 }R_t=\Pi_{\mathcal N^\perp,w}K_t,
\]
\[
\textbf{使其同时高于噪声、非秩一阴影、优于随机轴与随机同维子空间，并在预注册粗化下保持自然性。}
\]

如果这样的对象存在，那么它揭示的不是“玻璃盒被打破”，而是更克制、更难被伪造的结构极限：在 degeneration、recovery、interpretability 或 control 问题里，确实存在一个**不能被均值、主效应、平滑 nuisance、单模板标量轨道或坐标重命名吸收**的不可约剩余 sector。那时我们研究的就不是品牌叙事，而是一个真正的 finite-dimensional structural obstruction。

如果这样的对象不存在，那么同样会得到强结论，而且往往更强：我们将得到一个统一 no-go——对所有可容许三元组，所谓“复杂 collapse narrative”都可被归约为以下几类之一：低于噪声地板、秩一标量阴影、随机轴不可分、coarsening 不自然、或 gluing mismatch 可被局部 nuisance 吸收。那时研究的贡献不在于“没有找到阳性”，而在于**证明旧叙事并无对象同一性**。这正是 report(17) 到 report(21) 真正留下的数学价值，也是它们脱离 MaoField branding 之后仍然值得保留的全部核心。
