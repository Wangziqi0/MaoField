## Keep

- Scalar KL does not uniquely determine a vector field. Any lift from scalar
  KL to a mean-null object requires a preregistered slice schema, reference
  measure, projection rule, and normalization.
- LOSO weak survival is not a positive finding. Matched-mean and rank/residual
  gates remain necessary before any vector-field training loss is considered.
- Two-slice aggregate outputs cannot certify a fixed `J>=4` mean-null slice
  field.

## Deflate

- The full stack in report (4) -- semiparametric orthogonalization,
  common-weight transport, factor removal, and strict scoring/elicitation --
  is a useful bar for strong theory or paper-grade positive claims.
- It is not the minimum bar for the next local artifact. The current minimum
  remains:

  ```text
  raw-logprob/checkpoint mode
  + fixed preregistered slices
  + primary JSON
  + LOSO / matched-mean / rank-residual verdict
  ```

## Reject

- Do not treat "public GitHub 404" as blocking node36 local verification.
- Do not promote report (4)'s literature framework into a claim that MaoField
  already has a validated vector field.
- Do not turn the report into an authorization for GPU training or a new loss.
