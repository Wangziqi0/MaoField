# Nature Machine Intelligence policy verification

**Checked:** 31 August 2026  
**Scope:** official Nature Machine Intelligence, Nature Portfolio and arXiv-facing submission planning.

| Topic | Verified requirement | Official source |
|---|---|---|
| Article format | Main text up to 3,500 words excluding abstract, Methods, references and legends; abstract up to 150 words; up to six display items; Introduction without heading, Results, Discussion, Methods; Discussion without subheadings. | https://www.nature.com/natmachintell/content |
| Initial file format | Initial submissions may be Word, PDF or TeX/LaTeX and need not use production formatting. | https://www.nature.com/natmachintell/submission-guidelines/initial-formatting |
| Submission contents | Manuscript, cover letter and optional Supplement; up to ten Extended Data items. LLM use must be documented and LLMs are not authors. | https://www.nature.com/natmachintell/submission-guidelines/preparing-your-submission |
| Presubmission | Nature Machine Intelligence does not accept presubmission enquiries. | https://www.nature.com/natmachintell/submission-guidelines/presubmission-enquiries |
| Preprints | Nature Portfolio encourages preprints; they are not prior publication. DOI and licence should be disclosed and the record updated after publication. | https://www.nature.com/natmachintell/editorial-policies/self-archiving-and-license-to-publish |
| Data and code | Minimum data must be transparently available; central custom code must be available to editors and reviewers; restrictions must be disclosed; Data and Code availability statements are required. | https://www.nature.com/nature-portfolio/editorial-policies/reporting-standards |
| AI use | Human authors remain accountable and AI use must be disclosed; generative-AI artwork is not used in this release. | https://www.nature.com/nature-portfolio/editorial-policies/ai |
| Figures | Production-quality figures should be vector/editable where applicable, publication-sized and supplied with sufficient source data. | https://www.nature.com/natmachintell/submission-guidelines/aip-and-formatting |

The final R3 manuscript satisfies the word/display structure. Unknown identifiers, licences and access URLs remain `AUTHOR_INPUT_NEEDED`; no DOI, repository URL or submission status has been fabricated.
