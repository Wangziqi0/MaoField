### D-3.1 辩证唯物主义之标准次序 (毛实践论 + 列宁反映论 + 马克思自然辩证法之标准形式)

取代之前隐式的"回顾 → 哲学 → 实验 → 数学"颠倒, D-3 标准次序:

```
物质 (链之实际 GPU 行为 + 数据集 + 模型权重 + EMA 状态之物质性) →
实践 (跑链 + 实验 + 反映论 instantiate 的 D-PPL 桥 + Phase 5 + N≥8 + Family ablation 等) →
感性认识 (jsonl 数字 + Pearson r + bootstrap 置信区间 + 实验原始数据 surface) →

螺旋上升 (新循环之第一阶段实践)
```

**关键 binding**: 物质 + 实践是起点形式, 哲学 + 数学是从实践 + 物质之反映之回顾形式之结果 (含一定的能动反作用, 但不自命为起点之先验形式).
